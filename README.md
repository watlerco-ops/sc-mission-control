# Space Cowboy Mission Control

Live open job board for Watler & Co LLC dba Space Cowboy. Money on the table,
percent collected, highest leverage first.

**Live URL:** https://watlerco-ops.github.io/sc-mission-control/

## What is in here

| File | Purpose |
|---|---|
| `index.html` | The whole board. Self contained, logo and data baked in, no external calls except the font. |
| `robots.txt` | Keeps search engines out. |
| `.nojekyll` | Tells GitHub Pages to serve the file as is. |

## Updating the board

The board is a static file. To refresh it, replace `index.html` and commit.
GitHub Pages redeploys in about a minute. Everyone holding the link sees the
new numbers on their next refresh, no new link needed.

## Privacy

This page is not password protected. It carries client names, addresses, and
contract dollars. Search engines are blocked, but anyone with the URL can read
it. Treat the link like an internal document and do not post it publicly.
